# v1.5.1 — 전장 우선 선택과 아군 입력

전장·상대·아군을 입력할 때만 목록을 펼치고 완료하면 선택한 정보만 남긴다. 아군 궁합 점수를 만들거나 연결하지 않는 화면 패치다.

## 입력 흐름

- 역할 선택 → 전장 → 상대 조합 → 아군 조합 순서로 배치한다. 선호 영웅 설정은 여전히 선택 사항이다.
- 전장은 상대 인원과 무관하게 즉시 선택 가능하다. 모드·썸네일 방식은 유지하며 선택 직후 목록을 접고 이름·작은 사진·모드만 표시한다. 작은 화면에서는 사진을 생략하고 이름 위주로 보여준다.
- 처음 전장을 고르거나 `전장 없이 진행`을 누르면 상대 선택창이 열린다. 상대 5명을 이미 골랐다면 전장 변경 후 모든 선택창이 접힌다.
- 상대 5명을 채우면 영웅 목록은 자동으로 접히고 추천이 표시된다. 다음 카드의 `아군 선택`으로 아군을 입력한다. 아군은 4명이 채워지면 자동으로 접힌다.
- 상대·아군 모두 일부만 입력한 상태에서 `완료 · 접기`가 가능하다. 변경 버튼·빈 슬롯은 선택창을 열고, 채워진 슬롯은 그 영웅을 해제하며 선택창을 연다.
- 각 팀의 초기화는 해당 팀만 비운다. 전장·상대·아군 중 한 입력창만 펼친다. 모스트 화면을 다녀와도 상대·아군·전장을 보존한다.

## 아군 정원

| 내 역할 | 아군 탱커 | 아군 딜러 | 아군 힐러 | 본인 자리 |
|---|---:|---:|---:|---|
| 탱커 | 0 | 2 | 2 | 탱커 1칸 |
| 딜러 | 1 | 1 | 2 | 딜러 1칸 |
| 힐러 | 1 | 2 | 1 | 힐러 1칸 |

항상 탱커 1칸·딜러 2칸·힐러 2칸을 그린다. 본인 역할의 첫 칸은 `내 자리`로 예약하고 잠근다. 실제 내 영웅은 아직 선택하지 않는다. 선택 가능한 정원은 전체 정원에서 내 역할 1칸을 뺀 값이다.
같은 팀 중복 영웅과 초과 인원은 허용하지 않는다. 상대·아군에 같은 영웅이 있는 미러 구성은 허용한다.
플레이 역할을 바꾸면 기존 아군 중 새 정원에 맞는 인원만 선택 순서대로 유지한다. 같은 역할을 다시 고르거나 모스트 설정의 역할 탭을 바꾸는 것만으로 아군을 지우지 않는다.

## 상태와 후속 연결

- `App.tsx`의 `activeInput`은 `map | enemy | ally | null`이며 여러 입력창이 동시에 펼쳐지는 것을 막는다.
- 기존 `selected`는 상대 ID 목록이다. 새 `allyIds`는 본인을 제외한 아군 ID 목록이다. 두 목록은 독립적이다.
- `TeamPicker.tsx`는 팀 요약·5칸 슬롯·공용 영웅 목록을 제공한다. 펼친 팀만 영웅 목록을 렌더링한다. 아군 탱커 정원이 0인 경우 탱커 목록은 생략한다.
- `allySelection.ts`는 정원 계산·추가/해제·역할 변경 시 정리를 담당한다. `ROLE_LIMITS`와 영웅 데이터를 변경하지 않는다.
- 아군·상대·전장은 메모리에만 유지하므로 새로고침하면 초기화된다. 선호·가중치의 기존 저장 방식은 유지한다.

아군은 `recommend()`에 전달하지 않는다. 점수·등급·후보 필터·동점 처리·가능 포함·전체 영웅 추가 제안 규칙은 v1.5와 같다. 아군으로 선택한 영웅을 추천 후보에서 제외하는 동작도 이번에는 추가하지 않는다.
추후 궁합 Excel을 연결할 때는 영웅 ID로 검증된 데이터와 `allyIds`를 추천 계산의 명시적인 입력으로 연결한다. 이번 패치에 궁합 파일·가중치·등급 재산출은 포함하지 않는다.

## 글꼴

기존 내장 글꼴에는 일부 한글이 빠져 있어 대체 한글 글꼴이 없는 환경에서 빈 글자로 보였다. `src/ow-ui.woff`에 기존 글자와 현재 화면·영웅·전장·등급의 한글을 함께 포함했다. 기존 Noto Sans KR와 SIL Open Font License를 유지한다. 원본은 [Google Fonts의 Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr)이다.

## 검증

- `npm test`: 71개 통과. 새 7개 검사는 세 역할의 정원, 본인 제외, 초과·중복 방지, 모든 역할 전환, 잘못된 ID 정리를 확인한다.
- `npm run build`, `npm run portable`, `npm run grades:check` 통과.
- 단일 HTML 실행 검사: 전장 우선 선택, 단일 선택창, 자동/수동 접기, 수정·초기화, 역할 변경, 모스트 왕복, 전장 없이 진행.
- 변경 전 v1.5의 세 역할 추천을 저장한 뒤 같은 상대·전장에서 영웅·점수·등급·순위를 대조했다. 아군 선택·초기화 전후에도 동일했다.
- 기존 선택형 모스트·역할별 저장·가능 포함·부분 선호 추천·새로고침 복원도 확인했다.
- Chromium 1440·768·390·320px 화면에서 가로 넘침과 JavaScript 오류가 없었다. PC·모바일 스크린샷과 한글 포함 여부를 확인했다.

## 전달 범위

main의 v1.5에 덮어쓸 화면·역할 제한·테스트·문서·버전 파일만 전달한다. 상성/맵/등급 데이터, 계산 로직, 가중치와 배포 workflow는 기존 저장소 파일을 사용한다. 런타임 라이브러리를 추가하지 않았다. GitHub 업로드·Merge·배포는 사용자가 진행한다.
